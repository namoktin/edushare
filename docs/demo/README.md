# Ảnh chụp demo

Thư mục này chứa ảnh chụp màn hình phục vụ Chương 4 (mục 4.4 — Demo hệ thống).

Đặt các tệp PNG theo tên gợi ý dưới đây, sau đó chèn vào báo cáo bằng cú pháp ảnh Markdown
(từ `docs/bao-cao/` dùng đường dẫn `../demo/<tên>.png`):

| Tệp | Nội dung |
|---|---|
| `01-onboarding.png` | Màn hình nhập tên thiết bị, mã lớp, chọn vai trò |
| `02-library.png` | Thư viện tài nguyên với ba trạng thái 🟢/🟡/⚪ |
| `03-devices.png` | Danh sách thiết bị trong lớp (badge P2P/LAN, Admin) |
| `04-transfers.png` | Tab "Đang truyền": tiến trình và tốc độ MB/s |
| `05-resume.png` | Tạm dừng giữa chừng và tiếp tục (resume) |
| `06-preview-offline.png` | Xem PDF/video offline (badge 🟢) |
| `07-mobile-laptop.png` | So sánh bố cục mobile (tab) và laptop (sidebar) |

> Gợi ý: chụp ảnh khi chạy `npm start` và mở trên 2–4 thiết bị cùng Wi-Fi (xem `docs/TRIEN-KHAI.md`).
